|---|---|

| العملة الأساس | الليرة السورية — الأرصدة المجمعة والتقارير تُحتسب بها |

| السعر الثانوي | السعر الرسمي (المصرف) — يُعرض ويُخزن ويُحدّث، لكن ليس الافتراضي |

| تحديث الأسعار | تلقائي من المصدر الحالي (س بي توداي) لما يتوفر، ويدوي لما لا يتوفر (مثل اليوان غالباً) |
| جدول الأسعار | لكل عملة: سودا (شراء/بيع) + رسمي (شراء/بيع) + تاريخ + مصدر + هل يدوي |
| التحويل بين العملات | حسبة تلقائية بسعر السودا مع إمكانية تعديل يدوي للمبلغ الواصل |

| لا تراجع عن شكل التطبيق | الشكل العام والألوان والشاشات تبقى كما هي — التوسعة فقط |
