# 🗂️ خريطة الملفات وبيئة البناء — مشروع «محفظتي»

> آخر تحديث: 2026-11-18 بعد قراءة كاملة للكود (٣٥٠٠ سطر).

## بنية المشروع

```
mz\
├── app.json                 ← إعدادات إكسبو: الاسم، الحزمة (com.mahfazati.app)، الأيقونات، الشاشة الافتتاحية
├── package.json             ← المكتبات: إكسبو ٥٨، موجويل ٠.٨٨، تايب سكريبت ٦، راوتر، تخزين محلي
├── tsconfig.json            ← إعدادات تايب سكريبت
├── AGENTS.md                ← تعليمات إلزامية للوكلاء (لا تثق بذاكرتك عن إكسبو، فحص قبل الإنجاز...)
├── android\                 ← مشروع الأندرويد الأصلي (مولد + ربط توقيع) — ما يعدل يدوياً إلا بحذر
│   └── (build, .gradle, .kotlin) ← مخلفات بناء قابلة للحذف (تتولد من جديد)
├── assets\                  ← الأيقونات والشعار وشاشة الافتتاح
├── signing\
│   ├── mahfazati.keystore   ← 🔑 ملف التوقيع المقدس — لا مساس فيه
│   └── keystore.properties  ← بيانات التوقيع (كلمة السر والأسماء المستعارة)
├── scripts\
│   ├── build-apk.bat        ← سكربت البناء الحالي
│   ├── gen-icons.mjs        ← توليد الأيقونات من الصورة الأصلية
│   └── mirror.init.gradle   ← سكربت غرادل مساعد
├── docs\                    ← هذه الوثائق
└── src\                     ← كل الكود الفعلي
```

## أوامر البناء والفحص

```
npx tsc --noEmit                 ← فحص الأنواع (إلزامي قبل الإنجاز)
npx expo start                   ← تشغيل خادم التطوير
npx expo run:android             ← بناء وتشغيل على جهاز
node scripts/gen-icons.mjs       ← إعادة توليد الأيقونات
scripts\build-apk.bat            ← البناء الحالي عبر سكربت
```

- آخر ملف تثبيت مبني وموقع: المجلد الأب — «Mahfazati-Updated.apk» (٨٣ ميغا — المرحلة ٥ تقلل هذا).
- أمر بناء غرادل المباشر: من داخل مجلد android: `.\gradlew.bat assembleRelease` مع خصائص التوقيع.
