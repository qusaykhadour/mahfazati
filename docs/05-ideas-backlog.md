# 💡 الأفكار المؤجلة — مشروع «محفظتي»

> أفكار قُدمت على صاحب المشروع ولم تُنفذ بعد. لا تنفذ أي فكرة هنا بدون موافقته.
> الأفكار المعتمدة ضمن الخطة (تصدير/استيراد، الأمان، المظهر) موجودة في `01-workplan.md`
> — هذا الملف للأفكار **الخارج عن الخطة الحالية أو المؤجلة**.

## ميزات

- **معاملات متكررة** (رواتب، فواتير شهرية) — مع قرارات صاحب المشروع: ❌ بلا موعد ثابت
  إلزامي للراتب («هاد بالاتفاق»). إذا نُفذت يوماً: بلا تواريخ إلزامية، اقتراح بضغطة واحدة من السجل.
- **تنبيهات استحقاق الديون** — تاريخ استحقاق اختياري + إشعار قبل الموعد.
- **ميزانية شهرية لكل فئة** — حد شهري لكل تصنيف مع خط تقدم، ويمكن تجاوز بتحذير.
- **تقارير أقوى**: مقارنة الشهر مع الشهر السابق، أكبر خمس مصاريف، رسم خطي للرصيد عبر الزمن.
- **مرفقات صور الإيصال** — إرفاق صورة بالمعاملة (مكتبة اختيار صورة native — تحتاج بناء جديد).
- **بحث وتصفية بالسجل** — بالاسم/الملاحظة/الفئة/الفترة، يصير مهماً عندما يكبر السجل.
- **صفحة الشخص الواحد بالديون** — كل ما أخذت وما أعطيت للشخص نفسه بسجل واحد.
- **أرشفة الحسابات** — بدل الحذف الحاسم (الحذف حالياً يمسح معاملات الحساب معه!).
- **شاشة ترحيب أول فتح** — ٣ خطوات (الاسم، الحسابات) — منفذة ضمن المرحلة ٥.

## نظام (بنية)

- **تعدد اللغات** — عربي (أساس) + إنكليزي + روسي + صيني، اتجاه تلقائي حسب اللغة.
  معتمد مبدئياً من صاحب المشروع لكن **مؤجل** — بعد انتهاء مراحل العملات والأمان.
  الطريقة: استخراج كل النصوص المكتوبة يدوياً إلى قاموس ترجمة، ثم لغات إضافية.
- **عملات إضافية** — اليوان مطبق بالخطة؛ أورو وروبل كعملات بلاد مستقبلاً إن فتحنا بلداً ثانياً.
- **مزامنة سحابية اختيارية** — وضعت خارج التخطيط: تكسر مبدأ «البيانات محلية فقط»
  إلا إذا نُفذت بحساب مستخدم اختياري صريح. تبقى فكرة بعيدة المدى.
- **نسخة آيفون** — البنية جاهزة تماماً؛ يفتقر جهاز ماك للبناء المحلي. عبر بناء سحابي ممكن.

## شكل

- أيقونة وتقليل الحجم وسلاسة — ضمن المرحلة ٥ من الخطة، لا تكرار هنا.

## ملاحظات صيانة

- ثمانية ملفات سجلات بناء قديمة داخل المشروع (build*.log) — يمكن أرشفتها ثم حذفها عند الحاجة لمساحة.
- مجلد مخلفات البناء داخل المشروع (android\build وغيرها) قابل للحذف ويعيد توليد نفسه.
