# 📚 وثائق مشروع «محفظتي» — دليل القارئ

هذا المجلد هو **ذاكرة المشروع الرسمية**. أي وكيل ذكاء صناعي (أو مبرمج بشري) يكمل الشغل بعدنا
**ملزم** بقراءة هذه الوثائق أولاً والالتزام بها، حتى لا تضيع المعرفة ولا يُخبَص بالمشروع.

## ملفات الوثائق

| الملف | شو فيه |
|---|---|
| `01-workplan.md` | خطة العمل الكاملة: المراحل، التفاصيل التنفيذية، حالة كل مرحلة |
| `02-progress-log.md` | سجل التقدم الزمني: كل خطوة منعملها بتتسجل هنا بالتاريخ (ملاحق فقط، ما بينحذف) |
| `03-decisions.md` | القرارات المعتمدة نهائياً (ما يتغير فيها إلا بموافقة صاحب المشروع) |
| `04-file-map.md` | خريطة الملفات: وين كل شي بالكود، بيئة البناء، التوقيع، أدوات النظام |
| `05-ideas-backlog.md` | الأفكار والاقتراحات المؤجلة/المتبقية التي لم تنفذ بعد |
| `06-skills.md` | المهارات المتاحة على الجهاز ومتى تُستدعى لكل مرحلة |

## ⚖️ القوانين الإلزامية لأي وكيل يشتغل على المشروع

1. **قبل أي شغل**: اقرأ `03-decisions.md` و`01-workplan.md` — لا تخترق قرارات معتمدة ولا تغير الخطة إلا بموافقة صاحب المشروع.
2. **بعد كل خطوة شغل**: سجّل في `02-progress-log.md` — التاريخ، شو عُدّل، بأي ملفات، ولماذا. لا خطوة تبقى غير مسجلة.
3. **لو صار عطل أو خطأ**: سجّل المشكلة والحل في `02-progress-log.md` بقسم «الأعطال» حتى لا يقع نفس العطل مرتين.
4. **الرد على صاحب المشروع بالعربي الفصيح المكتوب يمين لليسار** — بلا حروف لاتينية وسط النص (استخدم أسماء عربية، والرموز التعبيرية مسموحة). أسماء الملفات التقنية تُكتب داخل كتل برمجية فقط.
5. **ملف التوقيع (`signing/mahfazati.keystore`) مقدّس** — لا يُعدل ولا يُحذف ولا يُستبدل، ومع أي تعديل عليه لازم نسخة احتياطية أولاً.
6. **بيانات المستخدم محفوظة محلياً على جهازه فقط** — أي ميزة جديدة يجب أن تبقي هذا المبدأ.
7. **قبل أن تعلن إنجاز أي مهمة**: شغّل فحص الأنواع (`npx tsc --noEmit`) — إن فشل، المهمة غير منجزة.
8. **لا تثق بذاكرتك عن إصدارات إكسبو** — اتبع تعليمات ملف `AGENTS.md` في جذر المشروع.
9. **لا تحذف شي من المجلد إلا إذا كان قابل لإعادة التوليد** (مخلفات بناء مثل مجلد build و node_modules).
10. **لا تبدأ ميزة جديدة قبل موافقة صاحب المشروع** على اسمها ومداها.
11. **استدعِ المهارة المناسبة قبل كل مرحلة** — راجع جدول `06-skills.md`: مهارة البناء والأمان وفحص الجودة مصنوعة خصيصاً لهذا المشروع وإجبارية في مواضعها.
